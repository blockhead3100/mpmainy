# Article Summarizer and Media Converter

This application is designed to help users summarize articles and convert YouTube videos to different formats, along with transcribing their content. It leverages the power of large language models (LLMs) for both summarization and transcription.

## Core Features

*   **Article Summarization:**
    *   Users can paste article text into a text box.
    *   The application utilizes an LLM to analyze and condense the article into a concise summary.
    *   The summarized text is displayed in a clear, readable format.
*   **YouTube Video Conversion and Transcription:**
    *   Users can input a YouTube video link.
    *   The application offers the ability to convert the video to MP3 or MP4 format.
    *   An LLM is employed to transcribe the audio content of the video.
    *   The transcription is displayed in a clear, readable format.

## Style Guidelines

The application follows a clean and simple design philosophy, prioritizing readability and ease of use.

*   **Primary Color:** Neutral white or light gray for optimal text readability.
*   **Secondary Color:** Light gray is used for input fields and subtle background elements.
*   **Accent Color:** Blue (#3498db) is used to highlight interactive elements and call attention to important features.
*   **Layout:** Clean, simple, and focused on readability.
*   **Icons:** Simple, recognizable icons for actions like copy and clear.
*   **Animations:** Subtle animations are used for loading states and user interactions to enhance the user experience.
