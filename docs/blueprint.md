# **App Name**: Article Summarizer and Media Converter

## Core Features:

- Article Input: A text box where the user can paste the article text.
- Article Summarization: Summarize article using a large language model. The LLM will act as a summarization tool. It will reason over the article and condense the article to its main points.
- Summary Display: Display the summarized text in a clear, easy-to-read format.
- YouTube Link Input: Allow the user to paste a link to a YouTube video.
- YouTube to MP3/MP4 Conversion: Convert a YouTube video to an MP3 or MP4 file.
- YouTube Video Transcription: Transcribe the audio from a YouTube video using a large language model. The LLM will act as a transcription tool. It will reason over the audio and generate the transcription.
- Transcription Display: Display the transcribed text in a clear, easy-to-read format.

## Style Guidelines:

- Primary color: Neutral white or light gray for readability.
- Secondary color: Light gray for input fields and subtle backgrounds.
- Accent: Blue (#3498db) for interactive elements and highlighting.
- Clean and simple layout with a focus on readability.
- Simple, recognizable icons for actions (e.g., copy, clear).
- Subtle animations for loading states and user interactions.
